# Hoichoi Khelaghor - Ultimate Play Zone for Kids

A marketing and information website for Hoichoi Khelaghor, a kids' play zone and entertainment facility located in Dinajpur, Bangladesh.

## Tech Stack

- React 18 + TypeScript
- Vite + TailwindCSS
- shadcn/ui components
- Framer Motion animations
- React Router DOM

## Development

```bash
npm install
npm run dev
```
